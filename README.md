## Descripción del Proyecto
Este proyecto consiste en el desarrollo de un sistema de reconocimiento facial
capaz de identificar rostros a través de una cámara.
El objetivo es aplicar conceptos de programación
inteligencia artificial y visión por computadora en un entorno práctico.
